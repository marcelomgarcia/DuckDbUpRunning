DuckDbUpRunning
===============

DuckDB Up and Running by Wei-Meng Lee. Published by O'Reilly Media, Inc.

# Dataset

Using the dataset [Public Sector Network](https://www.kaggle.com/datasets/mirzamilanfarabi/public-sector-network) because it has a good complexity with several files and it's still small enough to be uploaded to GitHub. 

The book itself uses the [2015 Flight Delays and Cancellations](https://www.kaggle.com/datasets/usdot/flight-delays), but the dataset is too big for GitHub.
